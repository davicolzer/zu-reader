# Security

Zu Reader works offline: it has no internet permission and keeps everything on the phone.

If you find a security problem, please **do not open a public issue**. Report it privately at
[Security → Report a vulnerability](https://github.com/davicolzer/zu-reader/security/advisories/new).
You will get an answer as soon as possible.

Only download the app from this repository's [Releases](https://github.com/davicolzer/zu-reader/releases).
APKs from other places may have been changed.
