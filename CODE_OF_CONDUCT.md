# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and respectful, assume good intent, and keep discussions about the project.

Problems can be reported privately to the maintainer through
[GitHub](https://github.com/davicolzer) or the [security form](https://github.com/davicolzer/zu-reader/security/advisories/new).
